# Juno releases

Juno is a voice-first agent for your Mac with its own browser. Anything that sends, buys, submits or deletes
waits for your yes.

This repository holds Juno's downloadable builds (see Releases). It is a private beta: builds are
for people who were sent a link.

Each release attaches the corresponding source of the bundled browser (GPL-3.0), as
`juno-browser-source-<version>.tar.gz`.
